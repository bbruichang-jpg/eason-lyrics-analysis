## 🚀 上传步骤

### 方法 1：直接上传（推荐）

1. **找到你的专辑封面文件夹**
   - 打开你的本地文件夹，找到所有专辑封面图片

2. **重命名文件**
   - 根据上方的映射表，将每个文件重命名为对应的文件名
   - 例如：将 `cover001.jpg` 重命名为 `U87.jpg`

3. **上传到项目**
   - 将重命名后的所有图片复制到项目的 `public/albums/` 目录
   - 如果使用 FTP/SFTP，直接上传到该目录

4. **刷新页面**
   - 打开浏览器访问 http://localhost:5000
   - 刷新页面，专辑封面就会显示出来

### 方法 2：使用批量重命名脚本

如果你有大量封面图片需要重命名，可以使用生成的脚本：

**Linux/Mac 用户：**
```bash
cd 你的封面文件夹目录
bash /workspace/projects/rename-covers.sh
```

**Windows 用户：**
```powershell
cd 你的封面文件夹目录
powershell -ExecutionPolicy Bypass -File /workspace/projects/rename-covers.ps1
```

然后手动编辑脚本，将 `"你的原始文件名X.jpg"` 替换为你实际的文件名。

## 📸 图片要求

### 推荐规格
- **尺寸**：正方形，推荐 500x500 或 800x800 像素
- **格式**：.jpg 或 .webp（推荐使用 WebP 以获得更好的压缩效果）
- **文件大小**：建议每张不超过 500KB
- **质量**：建议 80-90% 的压缩质量

### 支持的格式
- `.jpg`
- `.jpeg`
- `.png`
- `.webp`（推荐）
- `.gif`

## ⚠️ 注意事项

### 文件命名规则
- 空格会自动替换为下划线（`_`）
- 特殊字符会被移除（`/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`）
- 英文字母保持原样
- 中文字符保持原样

### 特殊处理
- 专辑 `?` 使用特殊 ID `album-367`
- 如果文件名包含特殊字符无法命名，可以使用专辑ID命名

### 后备方案
- 如果找不到对应的封面图片，系统会显示渐变色背景
- 图片加载失败时也会自动回退到渐变色背景

## ❓ 常见问题

**Q: 上传后没有显示封面怎么办？**
A: 检查文件名是否完全匹配（包括大小写），刷新页面并清除缓存。

**Q: 部分封面显示，部分不显示？**
A: 检查对应的文件是否存在，文件名是否正确。

**Q: 可以使用其他格式的图片吗？**
A: 可以，支持 jpg、jpeg、png、webp、gif 格式。

**Q: 图片显示模糊怎么办？**
A: 使用更高分辨率的图片，建议至少 500x500 像素。

**Q: 如何批量上传？**
A: 可以使用 FTP/SFTP 工具或直接拖拽到文件夹。

## 📞 需要帮助？

1. 检查文件名是否正确
2. 查看浏览器控制台是否有错误信息
3. 确认图片文件确实存在于 `public/albums/` 目录
