# 专辑封面文件夹

请将你的专辑封面图片上传到这个文件夹。

## 命名规则

为了让系统能够正确识别专辑封面，请按照以下规则命名你的图片文件：

### 方式 1：使用专辑名（推荐）
文件名格式：`专辑名.扩展名`

示例：
- `陈奕迅.jpg`
- `U87.jpg`
- `认了吧.jpg`
- `米·闪.jpg`

### 方式 2：使用专辑ID
文件名格式：`album-0.jpg`, `album-1.jpg`, `album-2.jpg`, ...

### 方式 3：自定义映射
如果你的文件名不匹配，我可以帮你创建一个映射文件，将专辑名与文件名对应起来。

## 支持的图片格式
- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.gif`

## 建议的图片尺寸
- 正方形：推荐 500x500 或 800x800 像素
- 文件大小：建议每张不超过 500KB
- 格式：推荐使用 JPG 或 WebP 以获得更好的压缩效果

## 上传步骤

### 方法 1：通过文件管理器上传（推荐）
1. 在你的本地文件管理器中找到专辑封面图片
2. 直接复制或拖拽到 `public/albums/` 文件夹中

### 方法 2：通过命令行上传
```bash
# 假设你的封面图片在 /path/to/your/albums/ 目录下
cp /path/to/your/albums/*.jpg /workspace/projects/public/albums/
```

### 方法 3：告诉我你的文件信息
如果不知道如何上传，请告诉我：
1. 你的封面图片存放在哪个文件夹？
2. 图片文件的命名规则是什么？
3. 总共有多少张封面图片？

我会帮你完成上传和配置。

## 注意事项

- 确保文件名与专辑名完全匹配（包括空格、标点符号）
- 如果专辑名包含特殊字符，建议使用专辑ID命名
- 上传后刷新页面即可看到新的专辑封面
